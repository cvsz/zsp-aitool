# Contributing

## Development Workflow

1. Create a feature branch from `main`.
2. Use conventional commits where possible.
3. Keep pull requests focused and reviewable.
4. Update documentation when behavior or architecture changes.
5. Ensure CI passes before merge.

## Commit Examples

```text
feat(prompts): add product generation workflow
fix(docs): align prompt pack with architecture
docs(readme): update quick start
chore(repo): update project metadata
```

## Pull Request Checklist

- [ ] Purpose is clear
- [ ] Changes are scoped
- [ ] Documentation updated if needed
- [ ] Prompt pack updated if needed
- [ ] CI passes
- [ ] No private local files included
