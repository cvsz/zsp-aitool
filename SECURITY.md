# Security Policy

## Supported Scope

This repository follows ZeaZDev security and operational hygiene standards.

## Reporting

For sensitive reports, contact the repository owner directly or use GitHub private vulnerability reporting if enabled.

Please do not disclose sensitive findings in public issues.

## Guidelines

- Keep production-impacting changes reviewable.
- Avoid committing local configuration, private credentials, generated dumps, or environment-specific files.
- Prefer least-privilege access patterns.
- Document operational assumptions clearly.

## Response Process

1. Triage the report.
2. Identify affected components.
3. Prepare a minimal fix.
4. Validate the change.
5. Document the remediation.
